# আমার বংশতালিকা (Family Tree) – Android অ্যাপ

Kotlin + Jetpack Compose + Room। সম্পূর্ণ অফলাইন, বাংলা UI।

## ফিচার
- সদস্য যোগ / সম্পাদনা / মুছে ফেলা
- বাবা, মা ও স্বামী/স্ত্রী নির্বাচন
- ছেলে/মেয়ে সন্তানের নাম লিখে এন্টার চাপলেই যুক্ত হয়
- প্রজন্ম অনুযায়ী ট্রি ভিউ
- ব্যাকআপ ও রিস্টোর (উপরের ডানের ⋮ মেনু)
- Release APK-তে R8 দিয়ে কোড অস্পষ্ট করা হয়

## GitHub দিয়ে APK
Actions ট্যাব → Build APK → Artifacts থেকে `FamilyTree-release-apk` নামান।

## সতর্কতা
`app/family-release.jks` শুধু ব্যক্তিগত ব্যবহারের জন্য। Play Store-এ দিতে চাইলে নিজের গোপন কী বানিয়ে বদলে নিন।
